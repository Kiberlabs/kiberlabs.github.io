Public Architecture Decision Records (ADRs)

The four core engineering decisions behind KiberLabs' reliability, low operational cost, and fast fixed-price turnaround.

ADR-001 · SQLite WAL + busy_timeout=5000

ACCEPTED
  • Context: Concurrent webhook workers and scrapers frequently crash default SQLite rollback journals with database is locked errors.
  • Decision: Enforce PRAGMA journal_mode=WAL, synchronous=NORMAL, and busy_timeout=5000+ across all single-node engines, with clean repository interfaces for PostgreSQL migration when multi-region scale is required.
  • Verification: 50-thread simultaneous read/write stress test passes with 0 lock errors in kiberlabs-benchmarks.

ADR-002 · Zero-Token Deterministic Sieving

ACCEPTED
  • Context: Routing raw catalog scrapes, spam webhooks, or noisy OCR records straight into LLMs wastes 85–95% of token spend and introduces non-deterministic failures.
  • Decision: Place strict Python / Pydantic v2 deterministic sieves (margin math, IBAN MOD-97, regex NLU, SLA gates) ahead of any optional AI step.
  • Verification: Processes 38,000+ SKUs/sec and 70,000+ NLU turns/sec locally at $0.00 API token cost.

ADR-003 · Non-Root Docker & Hardened Boundaries

ACCEPTED
  • Context: Internet-facing scrapers, file processors, and FastAPI webhooks are prime targets for SSRF metadata theft, path traversal, and webhook replay floods.
  • Decision: Ship multi-stage non-root Docker images backed by constant-time HMAC X-API-Key auth, sliding-window rate limits, private/metadata IP rejection, and atomic replay deduplication.
  • Verification: 100% block rate across 112 real Red-Team payloads in automated CI.

ADR-004 · Grounded FTS5 BM25 RAG & Abstention

ACCEPTED
  • Context: Vector-only RAG pipelines frequently hallucinate legal clauses, skip exact article IDs, and require expensive managed vector databases.
  • Decision: Use article-aware chunking with SHA-256 content hashes, SQLite FTS5 BM25 retrieval with strict query sanitization, and mandatory INSUFFICIENT_EVIDENCE abstention when grounding fails.
  • Verification: Sub-millisecond p50 retrieval with verifiable verbatim citations and zero FTS5 operator injection bypasses.
